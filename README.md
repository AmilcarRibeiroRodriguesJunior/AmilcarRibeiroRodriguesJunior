# 🚀 Projetos

## 📊 RelataAI

**RelataAI** é um projeto voltado para trabalhar com dados provenientes de arquivos como CSV e XLSX, buscando facilitar a organização, visualização e interpretação das informações.

O projeto explora a ideia de transformar dados brutos em **dashboards, relatórios e insights**, tornando a análise mais prática.

## 🚗 Acidentes de Trânsito em BRs do Rio Grande do Sul

Projeto acadêmico de **análise de dados sobre acidentes de trânsito nas rodovias federais do Rio Grande do Sul**.

O projeto envolve tratamento e exploração dos dados, além da utilização de informações geográficas para visualizar os acidentes e identificar padrões.
